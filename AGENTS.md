# Project guidance

For planning documents, follow the format in
`.cursor/rules/planning-format.mdc`: a clear French decision overview with a
visual diagram, followed by the detailed technical implementation in English.

The finance data can be read and edited from Claude Code through the local MCP
server in `tools/mcp/` (see `tools/mcp/README.md`); write tools are dry runs
unless called with `dry_run: false`.
