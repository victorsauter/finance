# Components

UI foundation for the Finance app: Tailwind v4 + shadcn/ui (Base UI primitives,
`base-nova` style) + TanStack Router. Everything a page needs to look and behave
like the rest of the app lives here.

| Folder | Holds |
| --- | --- |
| `ui/` | shadcn components (copied into the repo, editable). `button`, `card`, `input`, `select`, `dropdown-menu`, `dialog`, `alert-dialog`, `popover`, `tooltip`, `sonner`, `tabs`, `table`, `badge`, `separator`, plus `ThemeSwitcher` and `ConfirmProvider` |
| `layout/` | `AppShell`, `Page`, `PageHeader`, `Section` |
| `forms/` | `MoneyInput`, `NameInput` (wave 2 re-skins them) |

Add more shadcn components with `npx shadcn@latest add <name>` (config in
`components.json`). Import with the `@/` alias (`@/components/ui/button`).

## Page anatomy

A route component renders a `Page`, which renders a `PageHeader` and then
`Section`s (cards). Never add your own max width, horizontal padding or `<main>`.

```tsx
import { Page } from '@/components/layout/Page'
import { PageHeader } from '@/components/layout/PageHeader'
import { Section } from '@/components/layout/Section'

export function BackupRoute() {
  return (
    <Page>
      <PageHeader
        eyebrow="Settings"
        title="Backup and restore"
        description="Keep a copy of your budgets."
        actions={<Button>Download JSON</Button>}
      />
      <Section title="Export">…</Section>
    </Page>
  )
}
```

- `Page` is the single container (`--page-max-width`, `--page-gutter`), a
  vertical `gap-6` stack. It renders `<main>`. Wave 0 routes still wrap the
  legacy pages with `<Page as="div">` because those pages render their own
  `<main>`: when you migrate a page, remove its `<main>` and the `as="div"`.
- `PageHeader` renders the only `<h1>` of the page. `actions` is a slot for
  buttons or a menu.
- `Section` is a labelled card (`role="region"`, h2 title, optional description
  and `actions`). Use `contentClassName` for a grid inside the card. Reach for
  `Card` from `ui/` directly only for custom layouts (summary tiles, etc.).

The shell (`AppShell`) is mounted once by the root route
(`src/routes/__root.tsx`). It owns the sidebar, mobile header and dock, the sync
notice and the global error banner. Do not render them again in a page.

## Routing

File-based TanStack Router in `src/routes/**`. `src/routeTree.gen.ts` is
generated by the Vite plugin (committed so `tsc -b` works on a fresh checkout);
never edit it.

- `/` and `/transactions` accept `?m=YYYY-MM`. Read it with
  `Route.useSearch()` (typed `{ m?: string }`); invalid values are dropped by
  `validateMonthSearch` (`src/lib/month-search.ts`). Change it with
  `<Link to="/" search={{ m: '2026-03' }}>` or `useNavigate()`.
- `/operations`, `/sauvegarde` redirect to `/transactions`, `/backup`. Unknown
  URLs redirect to `/`.
- Use `Link` from `@tanstack/react-router` for navigation, never `<a href>`.

## Design tokens (`src/index.css`)

- **Colors**: semantic classes only: `bg-background`, `bg-card`,
  `text-foreground`, `text-muted-foreground`, `bg-primary`, `bg-accent`,
  `border-border`, `text-destructive`, `text-success`, `bg-success-soft`,
  `text-warning`, `bg-warning-soft`, `text-flow-income` (and the other
  `flow-*` Sankey colors). Light and dark values are defined once, switched by
  `<html data-theme>`. Use the `dark:` variant only when a token is not enough.
- **Spacing**: Tailwind's 0.25rem step (`p-4`, `gap-3`). No arbitrary rem.
- **Type**: `text-xs`, `sm`, `base`, `lg`, `xl`, `2xl`, `3xl`. Nothing smaller
  than `text-xs`.
- **Radius**: `rounded-md` / `lg` / `xl` / `2xl`, all derived from `--radius`.
- **Layout tokens** (CSS variables): `--sidebar-width`,
  `--sidebar-width-collapsed`, `--mobile-header-height`, `--dock-height`,
  `--mobile-top-clearance`, `--mobile-bottom-clearance`, `--page-max-width`,
  `--page-gutter`, and the `--z-*` stack. The shell already reserves room for
  the fixed header and dock; pages need no extra bottom padding.
- **Breakpoints**: `sm` 481px, `md` 761px (sidebar appears), `lg` 981px, `xl`
  1181px (sidebar expanded). Mobile first: write the phone layout, then `md:`.
- Prefer container queries (`@container`, `@lg:`) for page-internal layout
  so it does not depend on the sidebar width.
- Utilities: `glass-panel` (frosted shell surface), `shadow-card`, `bg-brand`
  (accent gradient), `sr-only`.

## Dialogs, confirmations, toasts

- Destructive or irreversible actions: `const confirm = useConfirm()` from
  `@/components/ui/confirm-context`, same API as before
  (`await confirm({ title, message, tone: 'danger' })`). Built on `alert-dialog`.
- Forms in a modal: `dialog`. Menus: `dropdown-menu`. Short feedback after an
  action: `import { toast } from 'sonner'` (the `Toaster` is mounted in
  `App.tsx`).
- Base UI uses a `render` prop where Radix used `asChild`:
  `<DropdownMenuTrigger render={<Button variant="outline" />}>`.

## Theme

`ThemeSwitcher` (`ui/`) keeps the previous contract: a group labelled
"Appearance" with buttons "System theme" / "Light theme" / "Dark theme"
(`aria-pressed`). The preference is stored under `finance-theme` by
`src/app/ThemeProvider.tsx`.

## Tests

Mounting `<App />` in a unit test works as before (the router is created per
mount and reads `window.location`; set it with
`window.history.replaceState({}, '', '/transactions')`). Routes resolve
asynchronously, so use `findBy*` for the first assertion.
